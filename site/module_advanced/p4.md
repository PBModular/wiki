# ▶️ Loader usage

First, you need to add the `use_loader` permission to the `config.yaml` file

::: danger WARNING
The `use_loader` permission is the most dangerous, as it grants the module full control over the bot's internal state, including loading/unloading other modules, installing/uninstalling them, and accessing potentially sensitive configurations. Grant this permission only to trusted modules.
:::

The object of the current (and only) `ModuleLoader` bot will appear in the `loader` attribute. Below only some functions are described, for a full list of features look in the [source code](https://github.com/PBModular/bot/blob/master/base/loader.py), the functions have dockstrings.
